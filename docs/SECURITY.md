# Security

Threat model → controls → where it's enforced and how it's tested.

| Threat | Controls | Enforced in | Tested |
|---|---|---|---|
| **Token theft** | The token lives only in Windows Credential Manager (`keyring`, service `ReelEngine`). Never in files, config, the DB, OneDrive, logs or command lines. `set-secret.ps1` and `reel connect` use hidden input and pass secrets via stdin. The Authorization header is used where the API allows (the refresh endpoint needs the query parameter by design). Every log line, stored error and raw API payload is redacted: token shapes, `access_token=`, Bearer/OAuth headers, JSON token fields and registered secret values; `paging` URLs are dropped. | `secrets.py`, `log.py`, `graph.py`, `cli.py` | `tests/test_config_log.py` (redaction), `tests/test_publisher.py` (no token in any DB column or raw payload) |
| **Account takeover** | Checklist for Yazeed: authenticator-app 2FA on Instagram and Meta, recovery codes kept offline, a unique password in a password manager, login alerts, a monthly review of connected apps, and a weekly Account Status check (SETUP.md). The app stays in Development mode with least-privilege scopes (no comments scope). | `docs/SETUP.md` | manual |
| **Accidental harmful or false post** | Dry-run by default. Live needs a LIVE-OK line in DECISIONS.md, a token, a passing `doctor --live` and a typed confirmation. Kill switch: `reel pause` / `data/PAUSE`, checked before every publish and again before `media_publish`. Cap of 1 post per day (hard max 3) and a 6 h gap. Facts gate (known-trap rules from `facts.yaml`) + legal gate (bait, guarantees, salaries, third-party ads, service CTA) + an independent critique (score ≥ 7) + technical QA; any failure means the reel is held, never posted. The learner can't change the gates or the hard limits. | `config.py` (HARD_*), `gates.py`, `qa.py`, `jobs.py`, `publisher.py`, `learner.apply_review` | `tests/test_gates_example.py` (+ the owner's private `test_gates.py`), `tests/test_learner.py`, `tests/test_publisher.py`, `tests/test_cli.py` |
| **Double posting / crash** | Every state change is persisted before its side effect; the container id is saved before upload and `publish_requested_at` before publish. On restart the container status is read back and the post found in `/me/media`. | `publisher.py`, `pipeline.py`, `db.py` | crash-at-every-step tests in `tests/test_publisher.py`, `tests/test_state.py` |
| **Prompt injection** (via transcripts, trend pages) | Writing tasks run the Claude CLI with **no tools** and `--safe-mode` in an empty sandbox. Only the trends task gets the read-only WebSearch/WebFetch; any other tool is refused in code. Prompts mark untrusted input as data. Outputs are schema-validated, then re-checked by the deterministic gates, so a manipulated output still can't pass the facts/legal gates. | `brain.py`, `prompts/*.md` | `tests/test_brain_vault.py` |
| **Supply chain** | Pinned `requirements.txt`; `pip-audit` (0 known vulnerabilities, see `docs/qa/security/pip-audit.txt`); `bandit` (0 issues after review; every `# nosec` states why); the ffmpeg archive sha256 is pinned and cross-checked on two hosts; fonts are verified against the GitHub blob hash; the Whisper model revision is pinned. No trojan-source bidi characters in the code (they are written as escapes). | `requirements.txt`, `scripts/bootstrap_assets.py` | `docs/qa/security/` |
| **Dashboard exposure** | Binds to 127.0.0.1 only (non-loopback hosts refused); GET/HEAD only; strict CSP (no inline script or style, no external requests); nosniff, no-referrer, frame deny; path-traversal-safe media routes; a Host-header check against DNS rebinding; no secrets rendered. | `dashboard/server.py`, `dashboard/build.py` | `tests/test_dashboard.py` |
| **Data loss** | Daily SQLite online backup (7 kept, checked with `quick_check`) plus a copy in OneDrive (the DB holds no secrets). Raw clips are moved out of OneDrive into `data/raw/` and kept; duplicates are moved, never deleted. | `jobs.py`, `intake.py` | `tests/test_intake.py` |
| **Vault damage** | The engine writes only inside `12 Social Media/`, only between its own markers, never in `10 Source Archive/`; traversal is refused. Preview folder until Yazeed enables it. | `vault.py` | `tests/test_brain_vault.py` |
| **Subscription abuse** | Brain call cap: 60 per 24 h. The API key is stripped from the child environment (no surprise API bill). | `brain.py` | `tests/test_brain_vault.py` |

**Legal note:** no paid promotion or third-party ads (Saudi Mawthooq rules): hard gate. The service CTA stays off until the offer page is live and the legal checklist (Freelance Document, e-commerce authentication on منصة الأعمال (business.sa), PDPL consent) is done. Only Yazeed can switch it on (`cta.service_enabled`).

**If a token leaks:** Meta app dashboard → regenerate the token (this invalidates the old one) → `reel connect` → `reel doctor --live`.
