# Reels Playbook v1: seed (EXAMPLE)

The machine-readable starting playbook the learner starts from is `playbook_v1.json` in this folder. The learner
writes v2, v3 … to `data/playbooks/` and keeps evidence tags: **OFFICIAL** (the platform said it), **OBSERVED**
(a named study or industry consensus), **FOLKLORE** (a common belief, unproven), **OURS** (learned from this
account's own data).

Locked rules are enforced in code (gates + learner validator) and can never be changed by the learner. Also locked:
the facts gate and no third-party promotion.

This example uses generic starting rules and even starting arms. Replace it with your own researched seed.
